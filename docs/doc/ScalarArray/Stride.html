    Strides and the models of loops #

    The parts of the specification of loops that name no element type, shared by all the arrays:

    • iterRange f lo hi x applies f lo, f (lo + 1), …, f (hi - 1) to x, in this order, and iterRangeRev f lo hi x applies them in the opposite order. They are the models of a loop whose step j maps its state by f j; the run_forInFrom and run_forInRevFrom lemmas of each array's InPlace.Tail run a loop to them, and iterRange_prod_of_snd drops the array from a loop that only reads it.
    • Stride is the affine index map i ↦ off + inc * i of a strided vector, such as the incx of a BLAS routine, the diagonal of a matrix or a column of a matrix stored by columns, and Stride.Fits s n size says that its first n indices are distinct and less than size. The arrays' modifyAt updates the elements at any index map, so a.modifyAt s.idx lo hi g is the model of a strided loop.

    A loop computes the USize copies of the offset and the stride once, before it starts: toNat_idx_toUSize gives the Nat value of s.off.toUSize + s.inc.toUSize * j for a step j of a stride that fits in an array in memory.

        source
        structure ScalarArray.Stride :
        Type

        The indices off + inc * i of a strided vector, such as the incx of a BLAS routine, the diagonal of a matrix or a column of a matrix stored by columns. It is plain data: Stride.Fits s n size says that its first n indices are distinct and less than size.

        • off : Nat

          The index of the step 0.

        • inc : Nat

          The distance between the indices of two consecutive steps.
