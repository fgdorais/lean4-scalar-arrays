    Byte order #

    Conversions between the arrays with elements wider than a byte and ByteArray, in little-endian (LE, least significant byte first) or big-endian (BE, most significant byte first) order, and in-place byte swaps of the integer arrays. Floats are converted through their IEEE 754 bits.

    The results do not depend on the byte order of the machine. That byte order is computed once, when the module is initialized: when a conversion asks for the machine's own order, it copies the whole array at once. Otherwise ofBytes… copies and then swaps the bytes of each element in place, and toBytes… is a loop of shifts and byte accesses, which the C compiler turns into whole-word loads, stores and byte swap instructions.

    Experimental. The names and types here may still change. import ScalarArray does not import this module; use import ScalarArray.Bytes.

    This module is generated by scripts/generate.py; edit scripts/bytes_template.py instead.
